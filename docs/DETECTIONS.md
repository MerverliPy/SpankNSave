# Detection rules

SpankNSave reports context pressure, rapid context growth, oversized prompts and system context, tool-schema bloat, oversized tool output, duplicate tool calls, high reasoning share, excessive assistant output, and retry waste.

Provider-reported token fields and model limits are authoritative. Prompt, system, schema, tool-output attribution, and savings values are estimates. Recommendations are advisory unless a reversible output cap is explicitly enabled in `enforce` mode.
